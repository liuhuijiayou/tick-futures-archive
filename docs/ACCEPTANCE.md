## 当前尚未证明

- 六所全规模在开盘峰值下的吞吐、完整日盘及相应夜盘，以及盘中真实物理断网恢复；不能用盘后 870 订阅或历史窗口替代。
- 交易所上游零漏发、SDK 未开放的逐笔事件、SDK 之前已丢失的整数纳秒精度。当前 SDK id/datetime 列实测 float64，系统保留原始位模式。
- 33 个郑商所代码的过早历史身份；保留并标记，不把 2016 数据直接当成当前 2027 月份合约的已证历史。
- 本机合盖、睡眠、断电或退出用户后的连续覆盖。LaunchAgent 要求用户登录；超过回溯窗口需要常在线环境或额外授权历史能力。
- 完整开盘日记录率尚未测到，日/月/年容量与传输预算 PENDING。磁盘告警 20 GiB、拒写 5 GiB，未开启自动删除。

当前目标尚未全部验收通过。采集服务保持运行，真实行情的 GitHub 验收必须先解决授权，再对实际全批次逐片重下载及独立恢复。
